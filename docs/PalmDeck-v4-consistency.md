# PalmDeck v4 设置页一致性 / 可发现性（P2）

> 状态：**已实施，已在 Mac Catalyst 实机看一遍**（方案 + 落地记录 + 实测表同文件，见 §8 / §9）。
> 来源：UX 走查第 P2 项（「一致性 / 可发现性」），排在 P1.5 之后执行。
> 范围：**只有设置页文案、分组与座舱/启动页里的同一处用词**，不动数据模型、
> 不动协议、不动存储键、不动布局画布。

---

## 1. 目标

P1.5 把「模板」并进了「预设」，但设置页本身是 P7 一路增量堆出来的：
分类按「谁先做」而不是按「用户怎么想」排，标题里混着动作词（「清空」）和空话（「参数」），
同一个动作在设置页和座舱里叫两个名字。这一轮只做三件事：

1. **同一个东西只叫一个名字**（清空画布 / 预设 / 电脑 / 可用电脑）。
2. **标题说得出这一组是什么**（不拿动作词或废话当分组头）。
3. **分类少而准**：2 个滑条的独立分类并进「操纵与手感」；
   每个 Section 都有头，且头与项不重复。

**不做**：视觉重排、图标大改、动效。

## 2. 现状与证据

### 2.1 分类与标题

| 位置 | 现在写的 | 问题 |
|---|---|---|
| 侧栏 `.profiles`（`SettingsView.swift:14`） | 「游戏预设」 | 分区头是「预设」(`:473`)、编辑条是「存为预设」；P1.5 后它还装「布局」预设，名字已经不准 |
| 侧栏「布局」第 1 段的头（`:687`） | 「模式」 | 里面是「编辑布局」开关 + 「放弃本次编辑」，**和模式无关**（模式是飞机/开车/手柄）；footer 却在讲模式 |

| 侧栏「触觉」→ 段头「反馈」→ 项「触觉反馈」（`:816`） | 一个词三遍 | 头没有信息量 |

### 2.3 搜索索引的标题不是界面上的字

## 3. 方案

### 3.1 分类（8 → 7）

```
连接 · 预设 · 布局 · 操纵与手感 · 触觉 · 外观 · 帮助
```

- `.profiles` 标题：「游戏预设」→ **「预设」**（它现在同时装整机与布局预设）；
  搜索关键词保留「游戏 / game」。
- **删掉 `.wheel` 分类**，「满舵角度 / 回正速度」并进「操纵与手感」，成为最后一段：

  | 段头 | 项 | footer |
  |---|---|---|
  | 方向盘 | 满舵角度、回正速度 | 「这两个是**全局项**：三个模式共用（不像上面的灵敏度/死区那样按模式分开）。回正速度 0°/s = 松手保持当前舵角。」 |

  理由：这两个值本来就是全局的，单独占一个顶级分类既薄又难找
  （想知道「方向盘为什么会自己回正」的人会先点「操纵与手感」）。
  搜索索引里的两条跟着搬到 `.controls`。

### 3.2 段头

| 位置 | 现在 | 改成 | 理由 |
|---|---|---|---|
| 布局 → 第 1 段 | 模式 | **编辑** | 段里就是「编辑布局 / 放弃本次编辑」 |
| 布局 → 第 2 段 | 清空 | **重置** | 动作词不当头；footer 保留「想回出厂布局去「预设」点「默认」行」 |
| 布局 → 撤销段 | （无） | **撤销** | 全页统一：每段都有头 |
| 预设 → 第 1 段 | 电脑侧 | **电脑** | 与「连接」页同名（都是「关于电脑的只读信息」） |
| 触觉 | 反馈 | **触觉反馈**（项改「开启振动」） | 头与项不再重复同一个词 |
| 方向盘 | 参数 | **方向盘**（并进操纵与手感后） | `` |

> 「电脑」vs「电脑端」：**名词用「电脑」**（分类名、段头、按钮、空态）；
> 「电脑端」只在**与 App 对举**时用（「电脑端版本」「App 与电脑端主版本号不一致」）
> —— 那里「电脑端」比「电脑」清楚。空态文案顺带具体化：
> 「没搜到电脑。确认**电脑上的 PalmDeck** 已启动、手机与电脑在同一 Wi-Fi。」

### 3.3 同一动作一个名字

- 「清空当前模式」→ **「清空画布」**（与座舱 `⋯` 一致）；设置页 footer 里补一句
  「只清『飞机』这一个模式」。
- 「仅布局」→ **「布局」**（与行尾章、搜索词一致）。
- 预设页两个存按钮改成短名，与段头/footer 的分工不再重复：
  **「存为整机预设」** / **「存为布局预设」**（原来是「将当前状态存为预设（整机）」/
  「将当前布局存为预设（仅布局）」）。
- 启动页：「高级设置」→ **「设置」**；「发现的电脑（点一下连接）」→ **「可用电脑（点一下连接）」**。
- 座舱编辑条的「存为预设」**保持不动**：「存为布局预设」多两个字，编辑条右侧是固定宽度
  （最窄机型上会把「完成」挤出去），而弹窗标题已经写清「存为布局预设」。

### 3.4 搜索索引与界面同字

`entries` 的 title 一律改成界面上真实存在的字，搜不到就补关键词：

| 分类 | 现在 | 改成 |
|---|---|---|
| 预设 | 存为预设 / 电脑轴映射表 | 存为整机预设 / 存为布局预设 / 电脑当前轴表 |
| 布局 | 自定义组件布局 / 预设里恢复默认 / 清空当前模式 | 组件布局 / 默认布局（关键词带「恢复 / 出厂 / 预设」）/ 清空画布 |
| 操纵与手感 | （新增）满舵角度 / 回正速度 | 方向盘两条 |

### 3.5 空态给下一步

搜索无结果时，除「没有匹配的设置项」再加一行灰字示例：
「试试「死区」「轴表」「预设」」。

## 6. 边界与不做

- **不动存储键**（`palmdeck_*` 一个不改）——所以老用户的设置与预设一字不动。
- **不动座舱编辑条布局**（横向空间是硬约束）。
- **不为「方向盘」加按模式分开**（那是行为变更，不是一致性；要改得先写行为方案）。
- **不做「设置页搜索高亮/跳转到具体项」**：现在只能跳到分类，这次不扩。
- **不做分类排序优化**（「连接」第一是为首启服务的，保持）。

### 8.4 顺手发现的两个工具坑（不是 App 的 bug）

1. Catalyst 上 `.buttonStyle(.plain)` 的小按钮（启动页「设置」折叠）**合成单击不生效**，
   要 `dd:` → `du:` 慢按（鼠标按下—拖—松开）才会触发。已写进 `~/.pi/agent/skills/shot/SKILL.md`。
2. `osascript -e 'tell application "System Events" to set frontmost of (first process whose name "App") to true'`
   在本机报 `-2741` 语法错误（缺 `is`），必须写 `whose name is "App"`。—— 这个坑会让“点击打到了终端而不是 App”并浪费时间排错，值得记录。
3. 设置页详情列表（`List`）**不接受 cliclick 拖拽，也不响应 `page-down`**；
   用 `CGEventCreateScrollWheelEvent`（`kCGHIDEventTap`）的 Python 小脚本把鼠标停在列表上滚动可解。
