# PalmDeck · Windows 真机验收清单（G4）

> **状态**：待执行（`docs/TODO.md` 的 G4）
> **用途**：把「发布候选」推到「正式投产」的唯一卡点 —— Windows 真机 + 真 iPhone 的端到端走查。
> **前提**：本项目至今只在 macOS（Catalyst）验证过；vJoy / ViGEmBus 驱动、游戏内识别、
> 防火墙、真机配对**从未在真 Windows 上跑过**。这份清单就是逐条补齐。

## 怎么写

一条一行，**每条都要留下证据**（截图 / `joy.cpl` 截图 / 游戏内绑定截图 / 控制台自检截图）。
结果只填：`通过` / `失败` / `跳过`（跳过要写原因）。失败项开 issue，不现场改代码。

验收机建议**干净**：没装过 vJoy、没配过防火墙规则的机器最好。

> 清单里点名的自检项 id、界面文案（托盘菜单 / failsafe 提示 / 止动点数值 / 引用的章节号）
> 都被 `tests/test_ci.py::TestChecklistMatchesTheCode` 锁在代码上 —— 改了代码忘了改清单会红。
> 所以写步骤时尽量引「会被测到的那个东西」，别只写自己的话。

## 0. 前置条件

- [ ] Windows 10 / 11 x64 **真机**（虚拟机里 vJoy 未必装得上，避免）
- [ ] 一台**真 iPhone**（不是 Mac Catalyst —— Catalyst 的点击行为与真机不同，见
      `docs/PalmDeck-v4-consistency.md` 结尾）
- [ ] 手机与电脑**同一 Wi-Fi**，关闭「AP 隔离 / 访客网络」（否则 UDP 7773 收不到）
- [ ] iPhone 与电脑都别连公司网络（组播/Bonjour 常被墙）

## 1. 安装（一次性）

驱动先装：

- [ ] 装 **vJoy**（飞行：虚拟摇杆）+ **ViGEmBus**（开车 / 普通游戏：虚拟 Xbox），**重启**

### A. 安装包（玩家路线 —— 至少把这条走完）

- [ ] 双击 `PalmDeck-Setup-<版本>.exe`（Releases 里的第二份资产）
- [ ] SmartScreen 拦 → 「更多信息」→「仍要运行」（**没买代码签名证书**，属预期行为）
- [ ] 向导是**简体中文**（看到英文说明 `packaging/ChineseSimplified.isl` 没被用上）
- [ ] 全程**不弹 UAC**（`PrivilegesRequired=lowest`）
- [ ] 安装目录 = `C:\Users\<你>\AppData\Local\Programs\PalmDeck`
      （在用户目录下 ⇒ **目录可写** ⇒ 自动更新才能原地替换 exe）
- [ ] 勾上「开机自动启动」→ 打开注册表编辑器看
      `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
      有名为 `PalmDeck` 的一项、值是**带引号的完整 exe 路径**
- [ ] 装完自动启动：托盘出现图标 + 控制台自动打开
- [ ] 控制台是**独立窗口**（没有地址栏 / 标签栏，标题就是 PalmDeck）——
      借用 Edge / Chrome 的「应用模式」；两个浏览器都没装时才退回默认浏览器标签页
- [ ] **图标与版本属性对得上**：资源管理器里 `PalmDeck.exe` 有产品图标（不是 PyInstaller 默认图标），
      「属性 → 详细信息」里 `产品名称 = PalmDeck`、有 `文件说明`、
      `文件版本` **等于托盘 tooltip 里的版本号**（截图）
- [ ] 目标机**免装 Python**（exe 已内置）
- [ ] 证据：向导截图 + 安装目录截图 + 属性截图 + 托盘截图

### B. 裸 exe（可选：确认 exe 自己也能活）

- [ ] 只把 `PalmDeck.exe` 拷到干净机器 → 双击 → SmartScreen →「仍要运行」
- [ ] 托盘图标是**产品图标**（与手机 App 同一个），不是自绘的青色方向盘
      —— 打包漏了 `packaging/PalmDeck.ico` 时会**静默**退回自绘（看到青色方向盘就说明漏了）

## 2. 自检必须全绿

控制台「**自检**」页（托盘菜单也有「自检…」，两个入口都只是打开控制台的自检页）。
> 留证据最省事的办法：服务跑着的时候，浏览器直接开 `http://127.0.0.1:8080/api/doctor`
> —— 同一份数据的完整 JSON 报告，**不用装 Python**（端口改过就用实际端口）。
> 源码目录里另有命令行版：`python palmdeck_doctor.py`（加 `--json` 拿同样的 JSON）。
> 只装了 exe 的验收机没有 Python —— 托盘与网页两个入口就是全部，**没有命令行子命令可敲**。

- [ ] `python` / 依赖若干 → ok
- [ ] `backend` 虚拟手柄设备 → ok（后端不是 `none`）
- [ ] `driver.vjoy` → ok（`sc query vjoy` 服务存在且状态是 `RUNNING`）
- [ ] `driver.vigembus` → ok（同上，服务名 `ViGEmBus`）
- [ ] `firewall` → ok（端口已放行）；若红/黄点「**修复**」后重测
- [ ] `listener.http`（控制台）/ `listener.ws`（控制台实时通道）/ `listener.udp`（手机输入）
      → **三条都 ok**（默认 8080 / 8765 / 7773；改过端口就以「配置」页里的为准）
- [ ] `lan` 局域网地址 → ok，且 IP 与手机同网段
- [ ] 证据：自检页全绿截图

## 3. 虚拟设备本机验证（不经手机）

- [ ] `Win+R` → `joy.cpl` → 看得到 **vJoy Device**
- [ ] vJoy 属性里动手机 App 的摇杆 → X/Y 轴跟着动（飞行模式）
- [ ] 切「开车 / 手柄」→ 系统里多出 **Xbox 360 手柄**（ViGEmBus）
- [ ] 浏览器开 `gamepad-tester.com` → 按键 / 扳机 / 摇杆都有响应
- [ ] 切模式时虚拟设备**干净切换**（不留残轴、不粘键）
- [ ] 设置 → 预设选「**遥控器双杆**」（仅飞机模式）：`joy.cpl` 里左杆
      **X 跟着方向舵 Rz 动、松手回中**，**Y 跟着总距动、松手保持**；右杆仍写横滚/俯仰
- [ ] 顶栏「**熄火锁**」锁上时推左杆 Y，`joy.cpl` 的总距**纹丝不动**；解锁后才动
- [ ] 证据：`joy.cpl` 截图 + gamepad-tester 截图

## 5. 游戏内绑定验收（G4 核心）

### WARDOGS（直升机，模式 = 飞机）

对照 `docs/PalmDeck-v4-game-profiles.md` §3.6 的定义，**逐轴**在游戏里绑一次并确认方向：

- [ ] 周期杆 → 俯仰 / 横滚
- [ ] 总距（collective）→ 游戏内油门 / collective，**方向正确**（推满 = 加油）
- [ ] 脚舵 → 偏航
- [ ] 反向对不对（反向轴设 `invX/invY/invYaw/invColl`（设置 → 操纵与手感 / 飞行前高级））
- [ ] **总距止动**：直升机总距上有 3 个止动点 **0% / 42% / 100%**
      （`Views/Widgets.swift:172` 的 `detents: [0.0, 0.42, 1.0]`）。42% 只是「按常规」取的中位 ——
      在游戏里对一下**悬停点落在第几格**，不对就记下正确数值（要改的就是这一个常量）
- [ ] 证据：游戏内绑定表截图 + 数值备注

### 欧洲卡车模拟（ETS2，模式 = 开车）

按 `docs/PalmDeck-v4-game-profiles.md` §3.6「ETS2 的两条必须在游戏内确认的事」：

- [ ] **LS Y 的归属**：drive 把**离合**送到 LS Y。ETS2 默认可能把 LS Y 当油门/刹车 →
      改成 `Clutch` 绑左摇杆 Y，油门 / 刹车只用 RT / LT（推荐方案 a）
- [ ] **序列式变速箱**：ETS2 里把变速箱设为 **Sequential**，`Shift Up` → RB、`Shift Down` → LB
- [ ] 方向盘满舵角度 / 回正速度在游戏里够用
- [ ] 证据：ETS2 设置截图

## 6. 安全与边界

- [ ] **failsafe**：飞行中关手机 Wi-Fi / 直接杀 App → `park_ms`（默认 2s）后**舵回中、油门保持**
      （控制台应显示「手机已离线，杆已回中（油门保持）」）
- [ ] **熄火锁**：App 冷启动总距**输出为 0**（`throttleHold` 默认锁上）→ 解锁后总距才动
- [ ] 手机切后台 / 锁屏 → 行为符合预期（不残留满舵）
- [ ] **第二部手机**抢连 → 被拒（allowlist / `mode_owner_ip`），第一部不受影响
- [ ] 拔掉 / 换掉一个驱动后重开 → 自检给出可读的红项 + 修复入口（不是一堆 traceback）

## 7. 打包 / 运维 / 软件式的那几条

- [ ] 托盘菜单勾上「**开机自启**」→ 重启电脑 → 托盘图标自己出现（不必手动跑 exe）
- [ ] **安装时勾的自启和托盘那个开关是同一个**：托盘里关掉「开机自启」→ 注册表那项
      真的没了 → 重启电脑不再自启（两处写不同键名就会打架）
- [ ] 换 Wi-Fi / 重启后防火墙规则仍生效（自检 `firewall` 仍 ok）
- [ ] 控制台「更新」页：打一个 tag 后能查到新版本号
- [ ] `PalmDeck.exe` 从 Releases 直链下载可运行
- [ ] **覆盖安装**：装新版安装包（托盘正在跑）→ 托盘进程被安装包自己请退、
      装完版本变新，且**布局 / 配置 / 配对都还在**
- [ ] **自动更新**：装一个旧版本 → 启动 → 自动下载并原地替换 →
      托盘 tooltip 版本变新，**安装目录里没多出乱文件**（不是解压出一堆散件）
- [ ] **卸载**：设置 → 应用 → PalmDeck → 卸载
  - [ ] 程序目录 / 开始菜单 / 桌面快捷方式 都没了
  - [ ] `HKCU\...\CurrentVersion\Run` 里那条**也没了**
  - [ ] `%APPDATA%\PalmDeck`（日志 / 配置 / 布局）**还在** —— 重装不丢布局
- [ ] 卸载后**重启电脑**：不会冒出「找不到 PalmDeck.exe」之类的报错
      （裸 exe 时代真实的病：exe 删了，自启项还指着它）
- [ ] 证据：安装目录前后对比截图 + 注册表截图
