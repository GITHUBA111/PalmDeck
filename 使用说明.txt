PalmDeck — 手机当开车 / 开飞机的杆，落地 / 菜单用电脑键鼠。

======== Windows 一键安装（推荐，只需一次）========
1. 解压后双击 setup_windows.bat
   自动：检查 Python → 装依赖 → 检查 vJoy / ViGEmBus 驱动（缺了会自动打开下载页）
2. 按提示装驱动，重启电脑一次
3. 再次双击 setup_windows.bat 直接进入桥接

想打成单个 exe（不用装 Python 也能跑）：双击 build_exe.bat → 得到 dist\PalmDeck.exe

PalmDeck.exe 是「罗技驱动式」托盘常驻软件：
- 双击启动：右下角托盘出现方向盘图标，后台跑桥接，自动开浏览器控制台；没有黑框窗口
- 重复双击 exe = 只打开已有实例的控制台（不会重复启动）
- 托盘菜单：打开控制台 / 检查更新 / 打开日志 / 开机自启 / 退出
- 自动更新：每次启动查 GitHub Release，有新版本自动下载 → 自替换 → 重启
- 日志文件：%APPDATA%\PalmDeck\palmdeck.log

======== 手动方式 ========
1. 电脑已装 vJoy（开始菜单能看到 Configure vJoy）；开车另装 ViGEmBus
2. 双击 start.bat，不要关窗口
3. 电脑浏览器会弹出控制台（概览 / 输入监测 / 配置 / 布局 / 更新 / 日志）和配对二维码
4. iPhone 同一 Wi-Fi，打开 PalmDeck App（自动发现电脑，或扫控制台二维码配对）。
   只支持横屏；首次会走「起飞检查单」：电脑装好 PalmDeck → 手机连同一 Wi-Fi → 进座舱直接玩
   （不再用手机浏览器打开网页座舱；网页控制台只在电脑上看）
5. 顶栏变绿后，中间切换三套硬件皮肤：飞机 / 开车 / 手柄
   - 飞机：总距杆（IDLE/FLY/MAX 止动）+ 脚舵 + 周期变距杆 + 仪表板（姿态球 / 扭矩 / 滚转俯仰）
   - 开车（欧卡等）：方向盘（多圈 + 回正）+ 离合 / 刹车 / 油门三踏板 + 序列式档杆 + 转速表 + 视角板
     方向盘 = 左摇杆 X；离合 = 左摇杆 Y；视角板 = 右摇杆（看后视镜）
   - 手柄：Xbox 皮肤（双摇杆 / 十字键 / ABXY / LB·RB / LT·RT / 视图·菜单），轴停发、不抢电脑键鼠
6. 电脑控制台「收包频率」应接近 60Hz（绿）；iPhone App 走 UDP 7773，也可走二进制 WebSocket
7. 飞机开火 = vJoy 按钮 16；按键可在电脑控制台「布局」/ App 设置里改名并同步
8. 触觉反馈：按键 / 踏板 / 档杆都会振动（iOS 原生 Taptic Engine）。
9. 落地 / 菜单：手机切「手柄」，App 停发所有轴（不抢 WASD），用电脑键鼠操作。

注意：网页手柄测试器（gamepad-tester 类）只能看到 Xbox（ViGEmBus），看不到 vJoy（DirectInput）。
开车方向盘 = Xbox 左摇杆 X；飞机杆位请进游戏绑 vJoy，别用网页测试器验证。

若窗口写 backend=none，右键 start.bat → 以管理员身份运行一次。
Steam 里对 WARDOGS 关掉 Steam Input。
