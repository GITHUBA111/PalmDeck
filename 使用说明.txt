PalmDeck — 手机当开车 / 开飞机的杆，步兵用电脑键鼠。

======== Windows 一键安装（推荐，只需一次）========
1. 解压后双击 setup_windows.bat
   自动：检查 Python → 装依赖 → 检查 vJoy / ViGEmBus 驱动（缺了会自动打开下载页）
2. 按提示装驱动，重启电脑一次
3. 再次双击 setup_windows.bat 直接进入桥接

想打成单个 exe（不用装 Python 也能跑）：双击 build_exe.bat → 得到 dist\PalmDeck.exe

======== 手动方式 ========
1. 电脑已装 vJoy（开始菜单能看到 Configure vJoy）；开车另装 ViGEmBus
2. 双击 start.bat，不要关窗口
3. 电脑浏览器会弹出控制台和二维码
4. iPhone 同一 Wi-Fi，扫码（或打开控制台里的地址）。
   手机只支持横屏；首次会走「起飞检查单」：填 IP → 连接 → 开启体感 → 校准 → 进入座舱
5. 顶栏变绿后：地上键鼠，上车切「开车」，上飞机切「飞机」（按住 0.4 秒切模式）
6. 飞机：双手横握，整机倾斜 = 周期变距 / 副翼升降舵。
   左滑条 = 油门 / 总距（带怠速 / 悬停 / 最大止动），右滑条 = 方向舵。
   中央 PFD 姿态球显示正在发出的杆位
7. HUD 的「锁定」保持当前杆位不回中（解锁后俯仰连续接上）；
   「校准」按当前握持姿态回中
8. 帽垫四向 = 视角（hat，只写 POV，不占 vJoy 按钮）；10 个按钮可在设置里改名（对应 vJoy 按钮 1–10）
9. 触觉反馈：按键 / 滑条止动 / 限位都会振动。
   iOS App 走原生 Taptic；Safari 网页版 iPhone 不振动（系统限制）
10. 电脑控制台「收包频率」应接近 60Hz（绿）；iPhone App 走 UDP 7773，Safari 走二进制 WebSocket
11. 切「步兵」后用电脑键鼠；飞机开火 = vJoy 按钮 16

注意：网页手柄测试器（gamepad-tester 类）只能看到 Xbox（ViGEmBus），看不到 vJoy（DirectInput）。
开车方向盘 = Xbox 左摇杆 X；飞机杆位请进游戏绑 vJoy，别用网页测试器验证。

若窗口写 backend=none，右键 start.bat → 以管理员身份运行一次。
Steam 里对 WARDOGS 关掉 Steam Input。
