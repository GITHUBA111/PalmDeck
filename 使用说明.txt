PalmDeck — 手机当开车 / 开飞机的杆，落地 / 菜单用电脑键鼠。

Windows 只需要记两件事：第一次双击 ①，以后双击 ②。
出任何问题（手机连不上 / 游戏里没有设备）→ 打开控制台的「自检」页。

======== ① 第一次：双击 setup_windows.bat ========
它会：检查 Python → 装依赖 → 跑一次环境自检 → 启动服务。
自检会告诉你缺哪个驱动（vJoy 飞机 / ViGEmBus 开车），点它给的链接装一个，
装完**重启电脑**，再双击一次 ① 即可。

======== ② 以后：双击 start.bat ========
右下角托盘出现方向盘图标，浏览器自动打开控制台。没有黑框窗口。
- 重复双击 = 只打开已有实例的控制台（不会启动第二个）
- 托盘右键：打开控制台 / 自检… / 检查更新 / 打开日志 / 开机自启 / 退出
- 鼠标悬停托盘图标能看到版本号
- 自动更新：每次启动查 GitHub Release，有新版本自动下载 → 自替换 → 重启
- 日志：%APPDATA%\PalmDeck\palmdeck.log

======== 自检页（唯一需要知道的地方）========
控制台 → 自检。服务会自己说清楚：
- 缺哪个驱动 → 一键打开下载页
- 防火墙没放行 → 一键放行（端口从配置读，改了端口也能一键重放行）
- 端口被别的软件占了 → 说清是哪个端口
- 依赖没装好 / 电脑没连局域网 → 直接说
手机连不上、游戏里看不到设备，先看这一页。

======== 手机端 ========
iPhone 装 PalmDeck App（同一 Wi-Fi），自动发现电脑，或扫控制台上的二维码配对。
只支持横屏；首次走「起飞检查单」。顶栏变绿后即可切 飞机 / 开车 / 手柄。

- 飞机：总距杆（IDLE/FLY/MAX 止动）+ 脚舵 + 周期变距杆 + 仪表板
- 开车（欧卡等）：方向盘（多圈 + 回正）+ 离合 / 刹车 / 油门三踏板 + 视角板
  方向盘 = 左摇杆 X；离合 = 左摇杆 Y；视角板 = 右摇杆
- 手柄：Xbox 皮肤；此时轴停发，不抢电脑键鼠，用电脑走路点菜单

电脑控制台「收包频率」接近 60Hz（绿）就对了。手机走 UDP 7773，也可走二进制 WebSocket。
飞机开火 = vJoy 按钮 16。按键可在控制台「布局」/ App 设置里改名并同步。
触觉反馈：按键 / 踏板 / 档杆都会振动（iOS 原生 Taptic Engine）。

======== 手动方式（不想用 bat）========
1. 已装 vJoy（开始菜单能看到 Configure vJoy）；开车另装 ViGEmBus
2. python start.py（或 python bridge.py，前台带控制台窗口）
3. 浏览器开 http://127.0.0.1:8080/
4. 想打成单个 exe：双击 build_exe.bat → dist\PalmDeck.exe

命令行自检：python palmdeck_doctor.py（--json 给机器读）

======== 注意 ========
- 网页手柄测试器（gamepad-tester 类）只能看到 Xbox（ViGEmBus），看不到 vJoy（DirectInput）。
  开车方向盘 = Xbox 左摇杆 X；飞机杆位请进游戏绑 vJoy，别用网页测试器验证。
- Steam 里对 WARDOGS 关掉 Steam Input。
- 手机连不上且自检页显示防火墙没放行 → 点「一键放行」（会弹管理员授权）。
