PalmDeck — 手机当开车 / 开飞机的杆，落地 / 菜单用电脑键鼠。

Windows 只需要记一件事：把安装包双击装一次，以后开机它就在右下角托盘里等着。
出任何问题（手机连不上 / 游戏里没有设备）→ 打开控制台的「自检」页。

======== ① 安装（只做一次）========
双击 PalmDeck-Setup-<版本>.exe。

- 若 Windows 弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
  这个包没买代码签名证书（一张证书要按年付费），报这个属于正常，不是病毒。
- 安装目录：C:\Users\<你>\AppData\Local\Programs\PalmDeck
  装在用户目录下 ⇒ **不需要管理员权限**，全程不弹 UAC；
  自动更新靠原地替换 exe，也只有用户目录才能这么干。
- 两个勾选框：
  「开机自动启动」= 以后开机自动进托盘（随时可在托盘菜单里关掉，装了不勾也行）；
  「创建桌面快捷方式」= 可选。
- 装完自动启动并打开控制台。

然后在控制台 →「自检」里看还缺什么驱动（vJoy 打飞机 / ViGEmBus 开车），
点它给的链接装一个，**装完重启电脑**（驱动要重启才生效），再开一次控制台。

======== ② 以后：托盘图标 ========
右下角托盘里是 PalmDeck 图标（和手机上那个是同一个）。没有黑框窗口。

- 关掉控制台窗口不影响服务，服务一直在托盘里跑
- 托盘右键：打开控制台 / 自检… / 检查更新 / 打开日志 / 开机自启 / 退出
- 鼠标悬停托盘图标能看到版本号
- 控制台是**独立窗口**（借用 Edge / Chrome 的「应用模式」打开），不是浏览器标签页
- 自动更新：每次启动查一次 GitHub Release，有新版本自动下载 → 原地替换 → 重启
- 日志：%APPDATA%\PalmDeck\palmdeck.log

======== ③ 卸载 ========
设置 → 应用 → 已安装的应用 → PalmDeck → 卸载（开始菜单里也有卸载项）。

- 会删掉程序目录和「开机自动启动」那一条
- **保留** %APPDATA%\PalmDeck（日志 / 配置 / 布局）—— 重装不丢你的布局
  想彻底清干净：卸载后自己删掉这个目录即可

覆盖安装（装新版本）直接用新安装包装一次就行，布局和配置都在。

======== 自检页（唯一需要知道的地方）========
控制台 → 自检。服务会自己说清楚：
- 缺哪个驱动 → 一键打开下载页
- 防火墙没放行 → 一键放行（端口从配置读，改了端口也能一键重放行）
- 端口被别的软件占了 → 说清是哪个端口
- 依赖没装好 / 电脑没连局域网 → 直接说
手机连不上、游戏里看不到设备，先看这一页。

======== 手机端 ========
iPhone 装 PalmDeck App（同一 Wi-Fi），自动发现电脑，或扫控制台上的二维码配对。
只支持横屏；首次走「起飞检查单」。顶栏变绿后即可切 飞机 / 开车 / 手柄。

- 飞机：仪表盘 + 总距杆 + 脚舵 + 周期变距杆 + 视角板（默认无按键，按键自己加）
  总距杆在 0 / 悬停 / 满三个点有感（过点强震、每 10% 轻震、松手吸附）；顶栏左侧「熄火锁」锁上则总距输出恒 0（默认锁上）
  飞过航模遥控器的：设置 → 预设 →「遥控器双杆」（Mode 2：左杆 = 总距 + 尾桨、右杆 = 副翼 + 升降；左杆总距松手**保持**，尾桨松手回中）
- 开车（欧卡等）：方向盘（多圈 + 回正）+ 离合 / 刹车 / 油门三踏板 + 视角板（默认无按键）
  方向盘 = 左摇杆 X；离合 = 左摇杆 Y；视角板 = 右摇杆
- 手柄：左 / 右摇杆 + LT / RT + ABXY / LB·RB 起步按键；油门 / 刹车 / 总距清零，不误触

布局不是死的：进「布局」可拖动 / 缩放 / 改名、自己加按键，存成预设（设置 → 预设）。

电脑控制台「收包频率」接近 60Hz（绿）就对了。手机走 UDP 7773，也可走二进制 WebSocket。
按键映射到 vJoy 按钮（二进制包按位 → b1…b16）。按键可在控制台「布局」/ App 设置里改名并同步。
触觉反馈：按键 / 踏板都会振动（iOS 原生 Taptic Engine）；周期杆过中位、总距过卡位也振。
预设里「遥控器双杆」是内置布局（只改组件、不碰手感），出现位置在飞机模式的预设列表里。

======== 注意 ========
- 网页手柄测试器（gamepad-tester 类）只能看到 Xbox（ViGEmBus），看不到 vJoy（DirectInput）。
  开车方向盘 = Xbox 左摇杆 X；飞机杆位请进游戏绑 vJoy，别用网页测试器验证。
- Steam 里对 WARDOGS 关掉 Steam Input。
- 手机连不上且自检页显示防火墙没放行 → 点「一键放行」（会弹管理员授权）。


======== 从源码跑 / 自己打包（开发者，可选）========
玩家用上面的安装包就够了。以下是不想用安装包时的手动路线。

1. 已装 vJoy（开始菜单能看到 Configure vJoy）；开车另装 ViGEmBus
2. python start.py（或 python bridge.py，前台带控制台窗口）
3. 浏览器开 http://127.0.0.1:8080/
4. 想打成单个 exe：双击 build_exe.bat → dist\PalmDeck.exe
5. 想连安装包一起打：双击 packaging\build_installer.bat
   （要先有 dist\PalmDeck.exe；需要 Inno Setup 6.5+，中文向导文件在 packaging\ 里）

第一次装环境也可以双击 setup_windows.bat：它会检查 Python → 装依赖 →
跑一次环境自检 → 启动服务。以后双击 start.bat。

命令行自检：python palmdeck_doctor.py（--json 给机器读）
调试用：设 PALMDECK_NO_UPDATE=1 关掉自动更新，设 PALMDECK_NO_TRAY=1 不开托盘
（前台常驻、Ctrl+C 退出）。
